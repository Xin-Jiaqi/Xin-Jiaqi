# IP and public-disclosure gate

This checklist supports engineering decisions and does not replace advice from the university, employer, collaborator, or patent counsel.

## Before a public issue, commit, preprint, talk, or release

- [ ] Identify authors, inventors, employers, funders, collaborators, and contractual ownership.
- [ ] Separate public infrastructure from unpublished algorithms, weights, scoring functions, candidate lists, and effect data.
- [ ] Search papers, patents, repositories, products, standards, and theses for every claimed technical feature.
- [ ] Record the closest prior art, differentiating features, measurable technical effect, and reproducible evidence.
- [ ] Decide whether to keep private, publish defensively, register software copyright, or file a patent application first.
- [ ] Confirm code, data, images, logos, and example structures can legally be redistributed.
- [ ] If an invention or utility model was completed in China and a foreign/PCT filing is planned, complete the applicable CNIPA confidentiality-review procedure before filing abroad; obtain professional advice on the exact route.

## Lower-risk public infrastructure (still requires review)

- Generic structure schemas, conventional file-format adapters, ordinary coordinate conversion, tests for published standards, CI, provenance plumbing, and independently derived, licensed, or redistribution-cleared group data are usually lower risk. Ownership, licensing, patent scope, and data rights must still be checked.

## Private until reviewed

- Any unpublished algorithm, objective or ranking function, threshold, claim-feature combination, candidate material, anomalous path, benchmark result, or demonstrated technical effect that may support a future filing.
